Transcribe all spoken dialogue from this video.
Return a JSON object containing a "segments" array.
Each segment must have:
- "start_ms": integer start timestamp in milliseconds
- "end_ms": integer end timestamp in milliseconds
- "text": verbatim spoken dialogue without paraphrasing
- "speaker_label": coarse speaker identifier, e.g. "Speaker 1", "Speaker 2", or character name
- "confidence": confidence score from 0.0 to 1.0

Rules:
- Capture every word spoken, including interruptions and overlaps.
- Millisecond timestamps must be precise.
- Do not include sound effects or music descriptions in the transcript.
- If unsure about a word, output your best phonetic transcription rather than omitting it.
